### 🤖 How I work with AI

I use **Claude Code** as an AI coding agent while I own the architecture, code review, and testing. Each project keeps a context file (`CLAUDE.md`) that records its architecture and rules, so every AI session starts informed and I spend less time re-explaining. I also turn repeated workflows into reusable skills and connect tools through MCP. Working this way is how I've shipped two apps solo while working and studying full-time.
